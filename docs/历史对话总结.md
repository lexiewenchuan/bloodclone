# 血染钟楼前端工具开发历史对话总结

## 项目概述

本项目是一个基于HTML5、CSS3和JavaScript的血染钟楼桌面游戏前端工具，提供了完整的游戏管理功能，包括座位管理、角色选择、剧本上传、多语言支持等。

## 开发时间线

### 初始开发阶段

**用户初始请求**：
- 创建前端页面，包含座位布局、角色选择、剧本上传功能
- 支持JSON脚本数据导入
- 实现多语言界面（中文/英文）
- 确保响应式设计和良好的用户体验

**核心功能实现**：
1. **座位管理系统**
   - 实现了圆形座位排列，使用三角函数计算位置
   - 支持添加、移除、清空座位
   - 实现了座位重命名、换座功能
   - 座位数量限制为20个

2. **角色选择系统**
   - 创建了角色选择弹窗，支持按团队分类显示
   - 实现了角色卡片的创建和显示
   - 支持角色悬停效果和能力描述弹窗
   - 实现了恶魔的伪装角色选择

3. **剧本上传功能**
   - 支持JSON文件上传和解析
   - 实现了剧本信息的提取和显示
   - 支持剧本Logo的显示
   - 按剧本数据更新角色列表

4. **多语言支持**
   - 创建了中英文语言文件
   - 实现了语言切换功能

## 技术挑战和解决方案

### 1. 圆形座位排列

**挑战**：实现圆形座位排列，确保座位均匀分布

**解决方案**：使用三角函数计算每个座位的位置
```javascript
const angle = (i / seatCount) * Math.PI * 2 - Math.PI / 2;
const x = Math.cos(angle) * radius + centerX - 40;
const y = Math.sin(angle) * radius + centerY - 50;
```

### 2. 角色数据解析

**挑战**：解析不同格式的剧本JSON数据，提取角色信息

**解决方案**：实现了灵活的JSON解析逻辑，支持不同数据结构
```javascript
const regularRoles = scriptData.filter(item => 
  ['townsfolk', 'outsider', 'minion', 'demon'].includes(item.team)
);
const parsedFabledRoles = scriptData.filter(item => item.team === 'fabled');
```

### 3. 多语言支持

**挑战**：实现无缝的语言切换功能，确保所有界面元素都能正确翻译

**解决方案**：创建了语言文件和翻译函数
```javascript
async function loadLanguage(lang) {
  try {
    const response = await fetch(`locales/${lang}.json`);
    translations = await response.json();
    currentLanguage = lang;
    updateLanguageUI();
  } catch (error) {
    console.error('加载语言文件失败:', error);
  }
}
```

### 4. 错误处理和稳定性

**挑战**：确保系统在各种情况下都能稳定运行，避免崩溃

**解决方案**：为所有关键函数添加了错误处理
```javascript
function selectRole(role) {
  try {
    // 确保角色对象存在
    if (!role) {
      console.error('角色对象不存在');
      return;
    }
    // 角色选择逻辑
  } catch (error) {
    console.error('选择角色时出错:', error);
    alert('选择角色时出错: ' + error.message);
  }
}
```
