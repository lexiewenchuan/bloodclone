# 🇨🇳 中国大陆访问部署指南 (China Access Guide)

由于 GitHub Pages 和 Vercel 提供的默认域名 (`*.vercel.app`) 在中国大陆经常遭受 DNS 污染或阻断，导致无法访问。

**经过验证，目前最稳定、低成本的解决方案是：**
👉 **GitHub + Vercel + 国内域名 (腾讯云/阿里云)**

---

## 🏆 推荐方案：Vercel + 自定义域名

此方案结合了 Vercel 强大的自动化部署能力和国内域名的稳定解析。Vercel 的部署服务器 IP 在国内通常是可以访问的，只要绑定一个自定义域名，即可绕过对 `vercel.app` 的阻断。

### 1. 准备域名 (以腾讯云为例)
你需要拥有一个域名 (如 `my-game.com`)。如果您还没有，推荐去 [腾讯云 (DNSPod)](https://dnspod.cloud.tencent.com/) 购买。

#### 🛒 购买指南
1.  **访问**: [腾讯云域名注册页](https://dnspod.cloud.tencent.com/)。
2.  **搜索**: 输入心仪的名称 (如 `blood-clocktower-game`)。
3.  **选择后缀**:
    *   **省钱秘籍**: 推荐 `.top`, `.xyz`, `.fun` 等冷门后缀，首年通常仅需 **¥1 ~ ¥10**。
    *   `.com` 虽经典但较贵 (~¥85/年)，个人项目非必须。
4.  **实名认证 (必须)**:
    *   根据法规，域名注册必须实名。
    *   **大陆居民**: 上传身份证。
    *   **台湾居民**: 必须使用 **《台湾居民来往大陆通行证》 (台胞证)**。暂不支持台湾护照或居住证。
    *   **港澳居民**: 使用 **《港澳居民来往内地通行证》 (回乡证)**。
5.  **无需备案**: 只要解析到境外服务器 (如 Vercel)，**不需要**进行 ICP 备案。

### 2. 在 Vercel 绑定域名
1.  登录 [Vercel 控制台](https://vercel.com/dashboard)，进入您的项目。
2.  点击顶部菜单 **"Settings"** -> 左侧 **"Domains"**。
3.  在输入框中输入您刚买的域名 (如 `my-game.xyz`)，点击 **"Add"**。
4.  Vercel 会提供一组解析记录，通常是：
    *   **Type**: `CNAME`
    *   **Value**: `cname.vercel-dns.com`
    *   *(或者 A 记录指向某个 IP)*

### 3. 配置 DNS 解析 (在腾讯云)
1.  回到腾讯云/DNSPod 控制台，找到您的域名。
2.  点击 **"解析"**。
3.  添加一条记录：
    *   **主机记录**: `@` (代表主域名，如 `my-game.xyz`) 或 `www`
    *   **记录类型**: `CNAME`
    *   **记录值**: `cname.vercel-dns.com` (复制 Vercel 给您的值)
4.  保存。等待约 1-10 分钟，解析生效后即可访问！

## 🚫 已过时/不推荐方案

### ❌ Gitee Pages (码云)
*   **现状**: 2024/2025 年起，Gitee 已**暂停向个人免费版用户开放 Pages 服务**。
*   **结论**: 除非您有企业版账号，否则无法使用此方案。

### ❌ GitHub Pages (直连)
*   **现状**: 域名 `*.github.io` 在国内访问极不稳定，经常超时或 404。
*   **结论**: 不可用作生产环境。
