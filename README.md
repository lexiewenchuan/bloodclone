# 血染钟楼助手（Blood on the Clocktower Helper）

一个面向 **《血染钟楼》说书人 / 主持人** 的 Web 辅助工具，用来提升线下主持效率：从座位管理、角色分配、夜晚行动，到投票记录与状态追踪，都可以在一个界面里完成。

---

## 简介

- **复杂规则可视化**：把《血染钟楼》的主持流程拆成多个清晰面板，降低说书人口播与记忆负担。
- **面向真实使用场景**：围绕圆桌座位、夜晚唤醒顺序、玩家状态、投票权等高频动作设计交互。
- **适合展示产品思维**：不仅有前端页面，还包含版本管理脚本、资源管理、部署配置与代理能力。
- **工程化交付**：支持本地开发、生产构建、静态部署以及部分服务代理逻辑。

---

## 核心功能

### 1. 魔典 / 圆桌管理
- 可视化展示座位与玩家分布
- 适合 5–15+ 人局管理
- 支持拖拽和状态调整

### 2. 角色分配与剧本支持
- 支持官方及自定义剧本
- 一键分配角色
- 辅助处理酒鬼 / 中毒 / 身份信息等状态

### 3. 夜晚行动流程
- 自动生成夜晚唤醒顺序
- 降低漏行动、错顺序、忘结算的风险
- 帮助说书人更稳定地控场

### 4. 投票与生死状态追踪
- 存活玩家默认带投票标记
- 死亡后自动切换相关状态
- 投票权可点击消耗 / 恢复
- 顶部信息栏实时同步剩余票数

### 5. 设备与体验优化
- 主要面向 **PC 端大屏** 使用场景优化
- 移动端访问会提示切换到 PC 端，以保证主持体验

### 6. 版本与脚本管理
- 提供一套辅助版本控制脚本
- 支持保存、发布、回退、查看历史版本
- 适合持续维护大量剧本与资源文件

---

## 技术栈

- **前端**：React 18 + TypeScript
- **构建工具**：Vite
- **UI / 样式**：CSS Modules + MUI + 部分 Tailwind 风格组织
- **资源处理**：本地脚本批量处理剧本与图片资源
- **代理 / 服务扩展**：内置 API / Worker 相关目录，支持与外部服务联动
- **部署**：Vercel / GitHub Pages


## 常用脚本

```bash
npm run save -- "commit message"   # 保存当前版本
npm run release                     # 发布版本
npm run undo                        # 回退最近一次变更
npm run history                     # 查看历史
npm run versions                    # 查看版本列表
```
